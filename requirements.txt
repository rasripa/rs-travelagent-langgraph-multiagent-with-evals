# Train Travel Agent demo -- pinned to the versions this project was built and
# verified against. Two pins are deliberate ceilings, not laziness:
#
#   mcp<2      mcp 2.x renames FastMCP to MCPServer and changes the server API.
#              AgentCore's documented MCP contract (stateless_http=True on a
#              streamable-HTTP server at 0.0.0.0:8000/mcp) is written against
#              the 1.x FastMCP surface, as are the AgentCore samples.
#
#   a2a-sdk<1  a2a-sdk 1.x replaced the pydantic type model with protobuf
#              (a2a_pb2) and swapped A2AStarletteApplication for route
#              factories. 0.3.x matches the AgentCore A2A samples and already
#              defaults its agent card to /.well-known/agent-card.json, which
#              is what the AgentCore A2A contract requires.
#
# Both ceilings are safe to lift later; see README.md "Upgrading the SDKs".
